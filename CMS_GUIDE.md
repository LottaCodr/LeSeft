# LeSeft Nigeria — CMS and handover quick guide

The following applies **after** the company-owned Sanity project and standalone Studio have been configured. The current prototype is not connected to a real CMS.

## Authorised editor checklist

1. Open the Studio URL supplied by the company administrator and sign in with your own authorised account.
2. Select **Company information** to update the approved wordmark/logo, tagline, Abuja office address, official email, telephone, LinkedIn URL, footer copy and shared call to action. Only publish contact details approved for public use.
3. Select **Pages**, then a page document. Edit its search title/description, hero heading and introduction, sections and list items. Home also has capability cards. Keep existing Home section keys unchanged; they control the layout. Add descriptive alternative text for each image.
4. Select **Publish**. The site is designed to revalidate cached content at about 60 seconds; allow for hosting/cache differences and verify the published page on desktop and mobile.
5. If the edit does not appear, check that you published the document, that the site is connected to the correct project/dataset, and that the Studio image and website hosting configuration are correct. Ask the administrator rather than sharing credentials.

## Editorial safeguards

- Initial wording and images are a concept, not approved company material. AI-generated images do not depict actual LeSeft offices, staff, partners, projects or locations. Replace every hero and card image, and obtain image rights and company approval.
- Never put credentials, API tokens, personal sensitive information or unpublished confidential project information in a public dataset.
- Review text, phone/email links, SEO descriptions, image accessibility, form routing and the company privacy notice before publication.
- Staff access is administered in Sanity; exact role and permission options depend on the company's plan. Remove access promptly when no longer required.

## Backup and recovery

- A company administrator should schedule dataset and media exports using the currently supported Sanity export process and keep copies, the source repository and deployment configuration in company-controlled storage.
- Protect secrets separately using the company's secret-management process; do not put them into an ordinary content export or the Git repository.
- Document retention, restore ownership and emergency contacts. Regularly test restoring a backup into an isolated dataset and verify both records and media. Merely scheduling a backup is not proof it can be restored.
- Domain renewals, hosting, email-provider delivery and security alerts should have company-owned billing and monitoring contacts.

## Training session suggested agenda

1. Account access and permissions; understand published versus draft content.
2. Update a page heading, a service item, a photo and its alt text.
3. Edit company details, publish and verify on desktop/mobile.
4. Check an enquiry reaches the approved mailbox; handle enquiries using the company privacy policy.
5. Review backups, incident contacts, updates and escalation. Handover is complete only after the team has practised these steps.
